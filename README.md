# 路面弯沉计算（弹性层状体系）

基于**弹性层状体系理论**计算沥青路面在圆形均布荷载（FWD / 标准轴载）下的弯沉。本仓库提供**两套独立实现**，求解同一物理问题，可相互对拍：

| 文件 | 形态 | 求解方法 | 输出 |
| --- | --- | --- | --- |
| [`index.html`](index.html) | 网页（纯前端，零依赖） | 层刚度矩阵 $\mathbf{K}=\mathbf{B}\mathbf{A}^{-1}$ + 列主元高斯消元 | 竣工弯沉 + **逐层验收弯沉**（分阶段施工） |
| [`pavement-deflection.py`](pavement-deflection.py) | Python 脚本 / 库 | 状态空间传递矩阵 $\mathbf{T}_i=e^{\mathbf{A}_i h_i}$ + 自适应积分 | 圆心表面沉降 |

两者用同一套默认结构（4 层沥青 + 2 层水稳 + 粒料 + 土基，共 81 cm）与 FWD 标准荷载（50 kN / φ300 mm）算出的竣工弯沉分别为 **14.26** 与 **14.27（0.01 mm）**，相差 0.07% —— 见[默认算例](#默认算例)与[数值校核](#数值校核)。

> 适用场景：路面结构设计方案的弯沉敏感性对比、施工分阶段验收标准的制定与复核、FWD 实测弯沉的量级预判。

## 计算方法

### 1. 力学模型

轴对称条件下，将路面视为 $n$ 层水平均质、各向同性的弹性层（最下层为半空间土基）。对第 $i$ 层（厚度 $h_i$、回弹模量 $E_i$、泊松比 $\mu_i$，剪切模量 $G_i=E_i/2(1+\mu_i)$），在 Hankel 变换域内取位移函数

$$
F(\xi,z)=\left(A+B\,z\right)e^{-\xi z}\quad\text{（向下衰减）},\qquad
F(\xi,z)=\left(A+B\,(h-z)\right)e^{-\xi (h-z)}\quad\text{（向上衰减）}
$$

由 $F$ 及其导数构造该层顶、底面的**竖向位移 $W$、径向位移 $U$、竖向应力 $S$、剪应力 $T$** 四个分量，组装成 4×4 层刚度矩阵

$$
\mathbf{K}=\mathbf{B}\,\mathbf{A}^{-1}
$$

底部半空间以解析边界条件封闭：

$$
\mathbf{K}_{h}=\begin{bmatrix}2G\xi a_{0} & -2G\xi a_{0}-2G\xi\\[2pt] 2G\xi b_{0} & -2G\xi b_{0}-2G\xi\end{bmatrix},\quad
a_{0}=\frac{2(1-\mu)}{4\mu-3},\; b_{0}=\frac{1-2\mu}{4\mu-3}
$$

将所有层刚度组装为整体刚度矩阵，施加表面单位均布压力（$S=-1$，$r\le a$），解线性方程组得到该 $\xi$ 下各节点的归一化位移 $\bar{W}(\xi)$。矩阵求逆与方程求解均采用**列主元高斯消元 + 行均衡**，提高病态矩阵下的数值稳定性。

### 2. 荷载中心弯沉

圆形均布荷载中心（$r=0$）的竖向位移由 Hankel 逆变换给出：

$$
w(0)=p\,a\int_{0}^{\infty}\bar{W}(\xi)\,J_{1}(\xi a)\,\mathrm{d}\xi
$$

其中 $p$ 为接地压力、$a$ 为承载板半径、$J_1$ 为一阶第一类 Bessel 函数。Bessel 函数实现为：$|x|<15$ 用幂级数（收敛到 $10^{-18}$），$|x|\ge 15$ 用渐近展开（含 $\sqrt{2/\pi x}$ 振幅与相位 $\omega=x-3\pi/4$ 修正）。

### 3. 数值积分策略

被积函数在低频段变化剧烈、高频段以 $J_1$ 振荡为主，故采用**分段变步长复合 Simpson 积分**：

| 区段 | 范围 | 步长 | 原因 |
| --- | --- | --- | --- |
| 奇异起点段 | $[0,\ \xi_0]$，$\xi_0=0.01/a$ | 解析修正 | $\bar W\sim C/\xi$、$J_1(\xi a)\sim \xi a/2$，被积函数有限 |
| 低频细段 | $[\xi_0,\ \xi_{\text{fine}}]$ | $0.001/a$ | 覆盖最薄层特征频率 $3/h$，捕捉 $\bar W$ 的快速变化 |
| 中频段 | $[\xi_{\text{fine}},\ 100/a]$ | $0.02/a$ | 以 $J_1$ 振荡为主 |
| 高频段 | $[100/a,\ 500/a]$ | $0.1/a$ | 被积函数已衰减到可忽略量级 |
| 尾部修正 | $[500/a,\ \infty)$ | 渐近解析 | 高频时顶层退化为半空间，$\bar W\to 2(1-\mu^2)/(E\xi)$，用 $\int J_1(t)/t\,\mathrm{d}t$ 补齐 |

细段上限 $\xi_{\text{fine}}=\max\left(20/a,\ 3/h_{\min}\right)$ 并封顶 $200/a$，避免极薄层导致积分点数爆炸。每个区段端点权重取 Simpson 的 $1/3$，内部奇偶点取 $4/3$、$2/3$；子区间数强制取偶数。

### 4. 逐层验收弯沉

施工是自下而上的。第 $i$ 层完工、上部结构尚未铺筑时，实测面是**该层顶面**，此时的受力体系应为「第 $i$ 层及其以下各层 + 土基半空间」。程序对每个阶段**独立重建并求解一次层状体系**：

$$
w_i^{\text{验收}}=w(0)\Big|_{\text{体系}=\{i,\ i+1,\ \dots,\ n\}}
$$

- $i=0$（顶层，即竣工状态）直接复用整体解，不重复计算；
- $i=n-1$（土基顶面）退化为单层半空间，可用 Boussinesq 解析解校核（见下）。

由于新铺层板体性强、模量普遍高于下层，弯沉自下而上**逐层下降**，这正是分阶段验收标准「下层松、上层严」的物理依据。

- **分隔符**自动识别：逗号 / 分号 / Tab（按首行出现次数择多）；

| 6 | 沥青混合料表面 | 71 | 16.53 | −13.7% |

算法对两个有解析解的极端情形做了验证：

| 校核工况 | 解析解 | 程序结果 | 相对误差 |
| --- | --- | --- | --- |
| 均质半空间（$E=60$ MPa，$\mu=0.4$，$p=0.707$ MPa，$a=150$ mm），$w=2pa(1-\mu^2)/E$ | 2.9694 mm | 2.9693 mm | 0.003% |
| 4 层全同材料（每层 20 cm）退化为均质半空间 | 2.9694 mm | 2.9693 mm | 0.003% |

## Python 版 (`pavement-deflection.py`)

命令行 / 库形式的实现，采用**状态空间传递矩阵法**，与网页版同源但实现路径不同，适合嵌入批量计算或作为参考解。

### 方法

状态向量 $\mathbf{X}=[\bar u,\ \bar w,\ \bar\sigma_z,\ \bar\tau_{rz}]^\top$ 满足 $\mathrm{d}\mathbf{X}/\mathrm{d}z=\mathbf{A}\,\mathbf{X}$，每层传递矩阵

$$
\mathbf{T}_i=\exp\!\left(\mathbf{A}_i\,h_i\right)\quad(\text{`scipy.linalg.expm`})
$$

半无限底层的衰减约束 $\mathbf{R}\mathbf{X}=\mathbf{0}$ 由 $\mathbf{A}$ 的广义特征向量（特征值 $-\xi$，2×2 Jordan 块）解析导出：

$$
\begin{cases}2G\xi\,\bar u-(1-2\nu)\,\bar\sigma_z+2(1-\nu)\,\bar\tau_{rz}=0\\ 2G\xi\,\bar w+2(1-\nu)\,\bar\sigma_z-(1-2\nu)\,\bar\tau_{rz}=0\end{cases}
$$

表面应力 Hankel 变换 $\bar\sigma_z(\xi,0)=-p\,a\,J_1(\xi a)/\xi$、$\bar\tau_{rz}=0$（$J_1$ 用 `scipy.special.j1`），圆心沉降

$$
w(0,0)=\int_0^\infty \bar w(\xi,0)\,\xi\,\mathrm{d}\xi\quad(\text{`scipy.integrate.quad`，自适应，奇点取 }1/a,\ 5/a,\ 10/a)
$$

内部统一 N–mm–MPa 制，接口层完成 cm↔mm、kN↔N、mm↔0.01 mm 换算。

### 依赖与运行

```bash
pip install numpy scipy
python pavement-deflection.py
# → 圆心处沉降 w = 14.27 (0.01 mm) = 0.1427 mm
```

作为库使用（文件名含连字符，需 `importlib` 加载）：

```python
import importlib.util
spec = importlib.util.spec_from_file_location("pd", "pavement-deflection.py")
pd = importlib.util.module_from_spec(spec); spec.loader.exec_module(pd)

les = pd.LayeredElasticSystem(
    layers=[(4,9800,0.25),(6,12500,0.25),(8,11500,0.25),(12,9000,0.25),
            (18,14000,0.25),(18,12000,0.25),(15,300,0.35),
            (float('inf'),60,0.4)],
    force_kN=50, radius_cm=15,
)
print(les.center_settlement())      # 14.27  (0.01 mm)
print(les.center_settlement_mm())   # 0.1427 (mm)
```

**输入约定**：`layers=[(h_cm, E_MPa, ν), ...]`，最后一层厚度填 `float('inf')` 表示半无限土基；输出 `center_settlement()` 单位 **0.01 mm**，`center_settlement_mm()` 单位 mm。非法输入（模量 ≤ 0、泊松比越界、非底层厚度无限等）抛 `ValueError` 并带层号。

### 校核

| 工况 | 解析 / 参考 | 本程序 |
| --- | --- | --- |
| 均质半空间 $E=60,\ \nu=0.4$（$w=2pa(1-\nu^2)/E$） | 2.9709 mm | 2.9701 mm（0.026%） |

## 局限与注意事项

- **弹性假设**：各层为线弹性、均质、各向同性，未考虑材料的非线性、应力依赖性（粒料与土基的模量随应力水平变化）、粘弹性（沥青的温度与加载速率依赖）以及层间不完全连续（滑移）；
- **静态解**：按静力等效处理 FWD 落锤荷载，未计入动力效应（惯性、阻尼、振动模态），因此与高频动力解存在差异；用于量级判断与方案比选足够，用于精确反演时需引入动力修正；
- **单点输出**：只计算荷载中心（$r=0$）的弯沉。FWD 的弯沉盆（$r=0\sim2000$ mm 多传感器）需要扩展 Hankel 逆变换到 $r\neq0$；
- **数值精度**：积分上限截断在 $\xi=500/a$，尾部以半空间渐近式补齐。极薄层（<1 cm）或模量比极端（>1000:1）时精度下降，程序已对 $\xi_{\text{fine}}$ 封顶，但结果应结合解析解复核；
- **验收值性质**：输出的逐层弯沉是**理论计算值**，用于制定或复核验收标准；实际验收还应叠加温度修正、季节修正、保证率与变异性（统计代表值）；
- **单位口径**：界面厚度用 cm、模量用 MPa，内部一律换算为 m 与 Pa，CSV 与界面保持一致。
